# Public Assets Directory

This directory contains static assets for the portfolio website.

## Structure

- `/images/` - Project images and avatars
- `/Downloads/` - Downloadable files (PDFs, documents)
- `/downloads/` - Additional downloadable content

## Missing Files

You'll need to add:
1. Your profile image as `Naoise.jpeg`
2. Project images in respective `/images/projects/` subdirectories
3. PDF documents in the Downloads folders
4. An `avatar.jpg` file for team member references

## Next.js Public Directory

This is the standard Next.js public directory where static files are served from the root of the domain.
